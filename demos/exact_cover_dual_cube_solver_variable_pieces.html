Combined A + B OBJ is one geometry file: Cube A is at X = 0 and Cube B is at X = 3 cube-edge lengths. The colored ZIP contains that OBJ plus a companion MTL file. Standard OBJ requires the MTL to carry object colors.

What is exact here?

The solver creates a bipartite graph from Cube A voxels to Cube B voxels. Each edge represents assigning one source voxel to one of the selected rigidly transformed pieces. A min-cost perfect matching uses every source and destination voxel exactly once. Therefore every displayed candidate has zero overlap, zero void, and zero out-of-bounds material. That is exact occupancy, not automatically a usable puzzle. Structural admissibility additionally requires connected, adequately sized, non-speckled pieces with bounded interface roughness. CAD reconstruction is promoted only after every piece is nonempty, face-connected, and above the minimum volume.
